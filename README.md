# FitBuddy AI

FitBuddy AI is an AI-powered fitness assistant project designed to help users with personalized fitness guidance and related wellness support.

## Features

- AI-powered fitness assistance
- User-friendly web interface
- Backend API support
- Static files for styling and frontend resources
- HTML templates for the application interface
